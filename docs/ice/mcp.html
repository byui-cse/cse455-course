Model Context Protocol

Model Context Protocol (MCP), a new standard for connecting AI assistants to the systems where data lives, including content repositories, business tools, and development environments.

MCP Architecture

  • MCP Hosts: Programs like Claude Desktop, IDEs, or your python application that want to access data through MCP
  • MCP Clients: Protocol clients that maintain 1:1 connections with servers
  • MCP Servers: Lightweight programs that each expose specific capabilities through the standardized Model Context Protocol (tools, resources, prompts)
  • Local Data Sources: Your computer's files, databases, and services that MCP servers can securely access
  • Remote Services: External systems available over the internet (e.g., through APIs) that MCP servers can connect to

Transport Mechanisms Deep Dive

MCP supports three main transport mechanisms:

  1. Stdio (Standard IO):
  2. Communication occurs over standard input/output streams
  3. Best for local integrations when the server and client are on the same machine

  4. Simple setup with no network configuration required

  5. SSE (Server-Sent Events):

  6. Uses HTTP for client-to-server communication and SSE for server-to-client
  7. Suitable for remote connections across networks

  8. Allows for distributed architectures

  9. Streamable HTTP (Introduced March 24, 2025):

  10. Modern HTTP-based streaming transport that supersedes SSE
  11. Uses a unified endpoint for bidirectional communication
  12. Recommended for production deployments due to better performance and scalability
  13. Supports both stateful and stateless operation modes
